# SOP-210 Tissue processing
Version 5 | Effective 2026-03-10 | Owner: Lead histotech

## 1. Purpose and scope
Covers loading, running and unloading the tissue processors TP-01 and TP-02, which take fixed tissue through dehydration, clearing and paraffin infiltration.

## 2. Choosing a program
Use the short biopsy program for small biopsies and the routine overnight program for resections and larger tissue. Never put resection cassettes on the biopsy program; under-processed tissue cannot be sectioned well. STAT biopsies may run on the short program during the day if a processor is free.

## 3. Processor alarm or failure during a run
If a processor alarms or stops mid-run, do not open the retort and do not drain it manually. The tissue stays in the last reagent, which protects it. Note the step and time shown on the display, call the lead tech or supervisor, and put the processor on maintenance in the LIMS through the normal approval. The supervisor decides whether to resume the run on the other processor using the tissue rescue program.

## 4. Reagent rotation
Rotate alcohols and xylene after every 5 runs or when the processor's reagent monitor says so, whichever comes first. Paraffin baths are changed weekly. Record every reagent change in the processor log.
