# SOP-410 Immunohistochemistry staining
Version 7 | Effective 2026-03-01 | Owner: IHC lead

## 1. Purpose and scope
Covers IHC staining (ER, PR, HER2, Ki-67, p53, CK7, CK20) on the IHC stainers IHC-01 and IHC-02.

## 2. Controls on every IHC slide
Every patient IHC slide carries an on-slide positive tissue control, and every run includes a negative reagent control. HER2 runs also include a multi-tissue control with known 0, 1+ and 3+ cores. A patient result is valid only if its controls show the expected staining.

## 3. Protocols and antigen retrieval
Use only the validated protocol assigned to each antibody in the stainer's protocol library; never edit a protocol to rescue a run. Antigen retrieval is built into each validated protocol. A new antibody lot is verified against known cases before use on patient slides.

## 4. Failed controls
If a positive control is weak or absent, or the negative control shows staining, none of the patient slides from that run are released. Repeat the whole run after the cause is found. If the failure points to the instrument rather than the reagent, follow SOP-420.

## 5. Turnaround
IHC ordered by 2 pm is stained the same day. ER, PR and HER2 on breast biopsies should be ready for the pathologist within 1 working day of the order.
